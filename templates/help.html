🚀 快速开始

1. 注册账号

访问 登录页面 注册账号，新用户注册即送 $1 试用额度。

2. 创建 API 密钥

登录后在控制台的「API 密钥」页面点击「新建密钥」按钮。

3. 开始调用

使用您的 API 密钥调用我们的接口即可。

📡 API 调用示例

Base URL

https://tokengo-d0cb.onrender.com

cURL

curl https://tokengo-d0cb.onrender.com/v1/chat/completions \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "model": "gpt-5.6", "messages": [{"role": "user", "content": "Hello!"}] }'

Python

from openai import OpenAI client = OpenAI( api_key="YOUR_API_KEY", base_url="https://tokengo-d0cb.onrender.com" ) response = client.chat.completions.create( model="gpt-5.6", messages=[{"role": "user", "content": "Hello!"}] ) print(response.choices[0].message.content)

JavaScript

import OpenAI from 'openai'; const client = new OpenAI({ apiKey: 'YOUR_API_KEY', baseURL: 'https://tokengo-d0cb.onrender.com' }); const response = await client.chat.completions.create({ model: 'gpt-5.6', messages: [{role: 'user', content: 'Hello!'}] }); console.log(response.choices[0].message.content);

❓ 常见问题

API Key 是什么？如何获取？

API Key 是您调用 AI 服务的凭证。登录后在控制台的「API 密钥」页面可以创建和管理您的密钥。

如何充值？

登录后在控制台的「充值中心」页面选择金额和支付方式（微信/支付宝），完成支付后联系我们确认即可到账。

支持哪些支付方式？

目前支持微信支付和支付宝。收款码可在控制台充值页面获取。

如何兑换卡密？

在控制台的「卡密兑换」页面输入卡密代码即可兑换额度。

API 调用有频率限制吗？

是的，默认每分钟最多 60 次请求，每日限额 10000 次。如需更高限额请联系客服。

余额会过期吗？

余额永久有效，不会过期。
