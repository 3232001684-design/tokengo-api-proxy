📡 API 调用示例

ChatGPT 风格调用

curl https://tokengo-d0cb.onrender.com/v1/chat/completions \ -H "Content-Type: application/json" \ -H "Authorization: Bearer YOUR_API_KEY" \ -d '{ "model": "gpt-5.4-mini", "messages": [{"role": "user", "content": "Hello"}] }'

Python 示例

from openai import OpenAI client = OpenAI( api_key="YOUR_API_KEY", base_url="https://tokengo-d0cb.onrender.com/v1" ) response = client.chat.completions.create( model="gpt-5.4-mini", messages=[{"role": "user", "content": "Hello"}] ) print(response.choices[0].message.content)

JavaScript 示例

import OpenAI from 'openai'; const client = new OpenAI({ apiKey: 'YOUR_API_KEY', baseURL: 'https://tokengo-d0cb.onrender.com/v1' }); const response = await client.chat.completions.create({ model: 'gpt-5.4-mini', messages: [{role: 'user', content: 'Hello'}] }); console.log(response.choices[0].message.content);

❓ 常见问题

API Key 是什么？如何获取？

API Key 是您调用 AI 服务的凭证。登录后在控制台的「API 密钥」页面可以查看和管理您的密钥。

额度用完了怎么办？

您可以在控制台的「充值/订阅」页面购买额度，也可以使用卡密兑换。我们支持支付宝和微信支付。

如何确保 API 调用安全？

请妥善保管您的 API Key，不要在公开场合分享。建议定期更换密钥，如发现异常使用请联系客服。

支持流式输出吗？

是的，我们支持流式输出（Streaming）。在请求中添加 `"stream": true` 即可启用流式响应。
